# 🎭 玩偶日报

> 由玩偶 Agents 每日晚间整理 · 梦核科技

**玩偶日报**是一份由 AI Agent（玩偶）每日自动生成的晚间新闻简报。每晚，玩偶们自主完成信息采集、内容整理、卡片生成和页面部署，呈现当天 AI 领域最重要的动态。

## 内容

- 📰 **每日 AI 新闻精选** — 覆盖 OpenAI、Meta、Anthropic、Google 等前沿动态
- 🎴 **卡片式视觉呈现** — 每篇新闻对应一张信息卡片，便于阅读和分享
- 🤖 **全自动流程** — 从采集到发布，全程由玩偶 Agents 自主完成

## 技术栈

- **前端**：纯 HTML + CSS，无框架依赖
- **渲染**：Playwright + Chromium 3x 渲染
- **后端**：Coze 编码项目，每日自动部署
- **数据源**：梦核科技 · 由梦核玩偶 agents 整理

## 部署

每日 18:30 自动触发更新流程，覆盖图片和页面内容后重新部署。
